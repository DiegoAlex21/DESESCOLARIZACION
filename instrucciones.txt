TUTORIAL: ARRANCAR CAMPUS CONNECT DESDE CERO (WINDOWS)
=====================================================

Este proyecto tiene dos partes que deben estar funcionando al mismo tiempo:

1. El backend (API), escrito en Python.
2. La aplicación móvil, escrita en Flutter.

La app necesita conectarse al backend para iniciar sesión y cargar información.
Estas instrucciones explican cómo ejecutar ambos en una computadora Windows.


1. PROGRAMAS QUE NECESITAS
--------------------------

Instala lo siguiente antes de empezar:

- Git for Windows, para descargar el proyecto desde GitHub.
- Python 3.10 o posterior.
- Flutter y su SDK de Dart (Dart 3.13.2 o posterior).
- Visual Studio Code, recomendado para editar el proyecto.

Para ejecutar la app en un teléfono Android también necesitas:

- Android Studio y el Android SDK.
- Java JDK 17.
- La herramienta Android SDK Platform-Tools (incluye adb).
- Un teléfono Android conectado por USB.

Después de instalar los programas, cierra y vuelve a abrir VS Code para que
reconozca los comandos nuevos. En una terminal de VS Code comprueba:

    git --version
    python --version
    flutter --version
    flutter doctor

Para usar Android, acepta las licencias si Flutter lo solicita:

    flutter doctor --android-licenses

Revisa el resultado de flutter doctor y soluciona los elementos necesarios para
la plataforma que vas a utilizar. Para ejecutar en Chrome no necesitas Android
Studio, un teléfono ni Java.


2. DESCARGA EL PROYECTO
-----------------------

Abre PowerShell o la terminal integrada de VS Code y ejecuta:

    cd C:\Users\diego\source\repos
    git clone https://github.com/DiegoAlex21/DESESCOLARIZACION.git campus_connect_python
    cd campus_connect_python

Si prefieres guardarlo en otra ubicación, cambia la ruta de la primera línea.
En adelante, reemplaza C:\Users\diego\source\repos\campus_connect_python por
la carpeta donde hayas clonado el repositorio.

El repositorio incluye una base de datos SQLite de ejemplo llamada
campus_connect.db. El backend la utiliza automáticamente al arrancar.


3. INSTALA LAS DEPENDENCIAS DEL BACKEND
---------------------------------------

Desde la carpeta principal del proyecto, crea un entorno virtual:

    cd C:\Users\diego\source\repos\campus_connect_python
    python -m venv .venv

Actívalo en PowerShell:

    .\.venv\Scripts\Activate.ps1

Si PowerShell impide la activación del entorno, no hace falta cambiar la
política del sistema. Ejecuta los comandos de Python usando directamente:

    .\.venv\Scripts\python.exe

Instala las dependencias del backend:

    python -m pip install --upgrade pip
    python -m pip install -r requirements.txt

Si no activaste el entorno virtual, utiliza:

    .\.venv\Scripts\python.exe -m pip install --upgrade pip
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt


4. ARRANCA EL BACKEND
---------------------

En la carpeta principal del proyecto, con el entorno virtual activado, ejecuta:

    python -m uvicorn app.api.main:app --host 0.0.0.0 --port 8000

Sin activar el entorno virtual, ejecuta:

    .\.venv\Scripts\python.exe -m uvicorn app.api.main:app --host 0.0.0.0 --port 8000

Deja esta terminal abierta mientras uses la aplicación. La API está lista
cuando aparezca un mensaje indicando que Uvicorn está ejecutándose en el
puerto 8000.

Comprueba el servicio en el navegador:

    http://localhost:8000/health

Debe responder:

    {"status":"ok"}

La documentación interactiva de la API está en:

    http://localhost:8000/docs


5. PREPARA Y EJECUTA LA APLICACIÓN FLUTTER
------------------------------------------

Abre una SEGUNDA terminal. Instala las dependencias de Flutter:

    cd C:\Users\diego\source\repos\campus_connect_python\campus_student_app
    flutter pub get

Ahora sigue las instrucciones de la plataforma que quieras usar.


OPCIÓN A: EJECUTAR EN CHROME
----------------------------

Comprueba que Google Chrome esté instalado. Con el backend todavía activo en
la primera terminal, ejecuta en la segunda:

    flutter run -d chrome --dart-define=CAMPUS_API_URL=http://127.0.0.1:8000

Flutter abrirá la aplicación en el navegador. Mantén abierta la terminal de
Flutter mientras uses la app.


OPCIÓN B: EJECUTAR EN UN TELÉFONO ANDROID POR USB
-------------------------------------------------

1. En Android, activa las Opciones de desarrollador y la Depuración USB.
2. Conecta el teléfono a la computadora y acepta en el teléfono el aviso para
   permitir la depuración USB.
3. En la segunda terminal, comprueba que ADB detecta el teléfono:

       adb devices

   El estado del dispositivo debe ser "device". Si dice "unauthorized",
   desbloquea el teléfono y acepta la autorización.

4. Configura el reenvío del puerto de la API por USB:

       adb reverse tcp:8000 tcp:8000

5. Consulta el identificador de Flutter:

       flutter devices

6. Ejecuta la aplicación reemplazando ID_DEL_DISPOSITIVO por el identificador
   que apareció en el paso anterior:

       flutter run -d ID_DEL_DISPOSITIVO --dart-define=CAMPUS_API_URL=http://127.0.0.1:8000

   Por ejemplo:

       flutter run -d PBT4PNQWPFMJY99D --dart-define=CAMPUS_API_URL=http://127.0.0.1:8000

Deja abierta la terminal del backend, la terminal de Flutter y la conexión USB.
La app usa el reenvío USB para acceder al backend local de la computadora.
Si desconectas el teléfono, vuelve a ejecutar "adb reverse" al conectarlo.


6. DETENER EL PROGRAMA
----------------------

Para detener Flutter, ve a su terminal y presiona q o Ctrl+C.
Para detener el backend, ve a la primera terminal y presiona Ctrl+C.


7. SOLUCIÓN DE PROBLEMAS
------------------------

"git", "python", "flutter" o "adb" no se reconoce:
    Instala el programa correspondiente, comprueba que esté agregado al PATH
    y reinicia VS Code para abrir una terminal nueva.

El puerto 8000 ya está en uso:
    Detén la otra instancia del backend antes de arrancar una nueva.

La app muestra un error de conexión:
    Comprueba que http://localhost:8000/health responda correctamente.
    En Android, confirma que adb devices muestre el teléfono como "device" y
    vuelve a ejecutar adb reverse tcp:8000 tcp:8000.
    Ejecuta Flutter con el argumento --dart-define mostrado en estas
    instrucciones; sin él, la app puede intentar usar otra dirección de API.

Falla la instalación de Flutter:
    Comprueba la instalación con flutter doctor y que el SDK de Flutter y Dart
    cumpla la versión mínima indicada en pubspec.yaml.

No uses el comando "flutter clean" como primer intento: elimina archivos de
compilación y puede hacer que la siguiente compilación tarde más.
